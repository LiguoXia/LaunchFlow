# 场景排序与快捷启动

适用版本：0.4.17。

## 我的场景：拖动排序

- 拖动场景卡片右上角的六点手柄，放到目标卡片左半边可排在它前面，放到右半边可排在它后面。绿色竖线提示插入位置。
- 手柄获得键盘焦点后，按 `Alt + 左 / 上` 向前移动，按 `Alt + 右 / 下` 向后移动。
- 搜索结果内也可排序，未显示的场景不会丢失。顺序在保存成功后立即更新，重启应用后保留。
- 编辑、运行、重命名和更换默认场景不会重排列表。新建、复制和导入的场景追加到列表末尾。

## 概览：快捷启动

1. 进入“我的场景”，点击卡片操作栏中的闪电图标。它位于“重命名场景”和“设为默认启动场景”的五角星之间。
2. 闪电实心高亮表示已添加。返回“概览”，在默认启动场景下方的“快捷启动”栏目即可看到场景名和“启动”按钮，无需重新加载应用。
3. 再次点击闪电可取消快捷启动。删除场景也会移除对应快捷项。
4. 快捷启动沿用“我的场景”的排序，重命名会同步显示；默认启动和快捷启动可以独立选择。
5. 点击“启动”执行已保存的场景。有参数或敏感动作时，仍使用原来的配置与确认流程。未保存的编辑器草稿不会被自动执行。

顺序和快捷启动选择保存在本机 SQLite 中；复制、导入场景不会自动添加快捷启动，这些本机偏好也不会写入场景导出文件。旧版本升级保留“我的场景”原有的最近更新顺序，快捷启动初始为空。

## 验证

- 核心测试覆盖旧数据库迁移、重启持久化、非法 / 过时排序回滚、新增 / 复制 / 导入追加、删除清理，以及场景版本、默认项、草稿和历史记录保持不变。
- `npm run test:scene-organization` 使用独立数据目录中的真实 Windows WebView2、Tauri IPC 和 SQLite。测试真实鼠标拖拽（包括搜索与跨行）、键盘排序、快捷项添加 / 取消、改名同步、应用重启与真实等待步骤运行。
- 模拟旧后台响应延迟返回、保存失败，验证界面保留已确认状态；验证参数配置弹框、复制与删除行为。
- 检查浅色 / 深色主题与 1240×820、920×640 视口，卡片无横向溢出。
- 桌面脚本只创建独立测试场景并执行短暂等待；不会运行用户的工作流。结果保存于忽略提交的 `test-results/scene-organization/`。

本次 Windows 验收不代表 macOS 实机已验证。
