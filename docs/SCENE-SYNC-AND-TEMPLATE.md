# 场景名称同步与 Windows 体验模板

适用版本：0.4.15（保留 0.4.14 的 QQ Secret 与简单编排拖拽修复）。

## 场景名称同步

从场景卡片进入工作流编辑器，在标题改名对话框或右侧“场景设置”修改名称后，点击侧栏“我的场景”或编辑器返回按钮即可看到新名称，无需额外点击“保存”。其他页面导航也会先等待名称同步。

名称作为场景元数据单独提交。尚未正式保存的步骤仍保留在草稿中，不会因为改名而提前生效或丢失。默认启动状态、运行历史中的旧快照保持原有语义。空名称、超长名称、版本冲突或存储失败会保留编辑器并显示错误，避免显示并未保存的新名称。

## 载入与体验

1. Windows 下进入“我的场景”，点击“载入体验模板”。
2. 查看说明，点击“载入并查看”。会生成“Windows 全步骤体验”主场景、一个配套子场景和两个应用配置。每次载入生成独立 ID，不覆盖已有场景或默认启动场景，也不会自动运行。
3. 主场景包含 42 步，覆盖现有全部 32 种步骤类型。每个步骤提供中文说明；条件与汇合在高级画布查看。
4. 保存手头工作，在编辑器点击“保存并运行”，按现有运行确认查看命令与 GUI 操作。每次运行会重新打开此模板自己的练习窗口，并按本次运行 ID 定位。GUI 操作结束后再展示记事本、文件夹和网页，避免外部窗口延迟打开时抢走焦点。运行过程中观察练习窗口；需要停止时在运行详情中取消。
5. 在运行详情查看命令输出、子运行和截图附件。结束后自行关闭本次打开的记事本、资源管理器、练习窗口和网页。

Windows 记事本用于启动与文件体验；资源管理器用于打开目录；默认浏览器打开本机说明页面。记事本没有密码框、下拉框或可拖动控件，因此 GUI 全类型体验使用随 LaunchFlow 打包的练习窗口，无需安装额外软件。网页服务仅监听 `127.0.0.1`，随练习窗口关闭而停止。端口在载入时选择；若之后被其他程序占用，重新载入模板即可分配新端口。

Secret 步骤使用新建的 `demo-<场景 ID>` 演示凭据。场景只存引用，实际值为固定的虚构示例，不需要真实账号密码。凭据不会随场景导出。

## 删除与重新载入

- 主场景和配套子场景可通过场景卡片的删除按钮分别删除。先删主场景，再删子场景，以免留下失效的子场景引用。
- 两个“模板 · …”应用配置可在“应用库”删除；已被其他场景引用时保留引用检查。
- “模板演示 · 可删除（非真实密码）”凭据可在“权限与凭据”删除。为保证复制或改编的场景仍能使用，删除场景不会自动删除凭据或本地说明文件。
- 内置模板入口始终保留，可再次载入。

## 验证

`npm run test:scene-template` 使用隔离数据目录，验证真实 WebView2 / IPC / SQLite 的即时改名、草稿保留、重启持久化、错误保留编辑器、保存并运行导航、模板载入、全部步骤执行、再次运行以及删除重载。测试使用虚构凭据并清理本次创建的练习进程和凭据，不操作现有用户场景或真实密码。

Rust 模板测试比对注册表中每种步骤类型，检查节点配置、连线、上游引用与子场景引用。Windows 实测结果在 `test-results/scene-template/report.json`；macOS 不显示此 Windows 模板入口。

2026-10-10 验证结果：新增桌面脚本 7 项通过，包括未经修改的 42 步流程连续执行两次，以及删除后重新载入。前端 12 项测试、Rust 核心测试和 Clippy 检查通过；既有需要手动启用的原生集成测试仍按配置跳过。模板实测使用真实 Windows 应用、TCP 服务和练习窗口，不模拟执行结果。
