# LaunchFlow v0.4.13

Windows x64 预发布验收版：在 LaunchFlow 内配置开机自动登录。

- 设置新增内置自动登录窗口：管理员授权后填写当前账户密码，支持本地/域账户和 Microsoft 账户；提供启用、更新密码和关闭功能。
- Windows Hello PIN 不能替代账户密码；现有 PIN 登录方式保留。密码写入 Windows LSA，不进入工作流、数据库、命令行或日志。
- 每次保存只验证一次密码，写入失败回滚，保存成功后自动登记 LaunchFlow 普通登录启动。
- 修复 Microsoft Autologon 说明链接及 Windows 登录选项可能随短时 worker 退出而关闭的问题；增加结果提示和复制地址。

升级后打开 **设置 → 启动与后台 → 在 LaunchFlow 中配置自动登录**，填写账户密码，保存后确认默认场景启动检查通过。应用不会自行重启电脑。

安装包和便携包均未签名，需手动升级；保留完整 native 目录。模拟存储及隔离窗口回归通过，未使用真实密码、修改本机自动登录或进行真实重启。实际 Windows 凭据验证、UAC 与开机自动登录仍需安装后验收；不是 macOS 验收版本。

详情：[内置自动登录配置说明](../IN-APP-AUTOLOGON.md)。验证项目见 verification.json。
