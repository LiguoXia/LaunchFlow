# LaunchFlow v0.4.16

Windows x64 预发布验收版，集中优化“权限与凭据”和“导入与导出”的表单样式。

- 添加 / 更新凭据弹框使用统一的内容区和底部操作栏，左右保留 24px 留白；调整标签、说明和输入框间距，补充填写提示与取消按钮。
- 导入路径、导出场景和资源映射的输入框 / 下拉框统一字号、内边距与下拉箭头，控件与操作按钮对齐。
- 导入与导出卡片之间增加间距，窄窗口下自动换行，适配浅色和深色主题；保留原生下拉框的键盘操作。

本次不改变凭据存储、导入校验、映射及导出逻辑。提供 Windows x64 安装包和便携 ZIP，均为未签名构建；更新器未配置，请手动下载安装包升级。macOS 尚未完成实机验收，本版本不标记为 V1 Release Candidate。

验证：前端 12 项测试通过；在独立数据目录的真实 Windows WebView2 中检查凭据弹框、导入导出与资源映射，覆盖浅色 / 深色主题及 1240×820、920×640 窗口尺寸。输入、下拉选择与取消操作正常，映射表无横向溢出，未出现页面脚本错误。

公开验收摘要见 `verification.json`，文件 SHA-256 校验值见 `SHA256SUMS.txt`。
