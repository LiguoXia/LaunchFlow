# LaunchFlow v0.4.26

工作流编辑器的下拉框支持按名称排序和输入模糊搜索，应用与窗口较多时也能快速找到目标。

- 覆盖「启动应用」的应用列表、「激活窗口」的桌面 / 托盘窗口列表、其他 GUI 步骤的窗口列表、子场景、步骤选项、运行平台、失败策略、场景设置与运行参数。
- 中文按拼音、英文按字母、数字按自然顺序排列。例如 Code 2 排在 Code 10 前。
- 点击下拉框即可输入搜索。支持名称片段、按顺序省略字母的简写、大小写 / 全角兼容和空格分隔的多个关键词。例如 `cdx` 可找到 Codex，`vsc` 可找到 Visual Studio Code，`微` 可找到微信；应用还可通过进程名、可执行文件名或 macOS bundle ID 查找。
- 方向键切换候选项，回车确认，Esc 取消搜索。中文输入法组词确认不会误选候选项。取消搜索或移开焦点会恢复原来的选择；仅输入文字不会更改已保存配置。
- 同名应用保留独立选项并展示进程名；保存后仍使用原来的应用 / 场景 ID 和稳定窗口定位信息。打开旧场景无需重新配置。
- 下拉列表适配浅色 / 深色主题、滚动区域、窄窗口和运行配置弹窗。必填参数需要实际选中候选项。

保留 v0.4.25 的「复制文本」步骤以及微信、ChatGPT / Codex 托盘激活修复。

验证命令：`npm test`、`npm run build`；Windows 实际编辑器验收使用 `npm run test:searchable-selects`，覆盖排序、模糊匹配、同名项、键盘 / 输入法、保存回填、窗口定位与必填参数弹窗。托盘、录制窗口选择和触发器使用现有回归脚本验证。

提供 Windows x64 安装包 / 便携 ZIP，以及 macOS Intel、Apple Silicon 的 DMG / ZIP。macOS 最低版本为 13。此版本仍为预发布：Windows 无发行证书签名；macOS 使用 ad-hoc 签名，未公证。自动更新未配置，请手动升级。
