# LaunchFlow v0.4.11

Windows x64 预发布验收版，修复微信等自绘窗口录制后“窗口已激活、点击显示成功但没有效果”的问题。

旧版把自绘窗口识别为整个 Window，并点击其中心。现在在鼠标按下时记录实际相对位置，保留连续点击；拾取器也支持具体位置。输入前检查遮挡及焦点，旧的整窗点击会提示重新录制，不再误点窗口中心。复制诊断日志增加点击方式、定位来源、命中结果与投递事件数，不包含坐标或聊天内容。

**升级后需要重新录制此前无效的点击步骤，或用 Pick Element 重新拾取。原始位置未保存在旧数据中，无法自动恢复。激活窗口步骤与应用授权可保留。**

下载附件包括安装包、便携包、SHA-256 校验文件、manifest 和验证记录。便携版需完整解压并保留 native 子目录。制品未签名，自动更新未配置；使用安装包手动升级。

独立自绘窗口验证实际点击结果，使用真实原生录制和 Tauri/Rust 工作流；不操作用户微信聊天。具体通过项目见 `verification.json`。macOS 二进制、签名、公证、真实更新与干净系统安装验收仍不在本次交付范围内。本版不是 V1 Release Candidate。
