# LaunchFlow v0.4.19

Windows x64 本地验收版，统一应用字体与字号，重点改善场景设置的可读性。

- Windows 中文界面优先使用微软雅黑 UI，macOS 保留系统字体与苹方；使用系统文字渲染和常规字重。代码、日志与表达式使用带中文回退的等宽字体。
- 正文统一为 15px，常用按钮与列表为 14px，辅助说明至少 13px；清理页面中原有的 7–11px 固定小字。标题保持独立层级。
- 场景设置与步骤配置的标签、输入框使用 15px，说明使用 13px；右侧面板常规宽度由 266px 扩大到 360px，窄窗口也保留 330px。敏感操作与重复执行策略改为简洁中文选项。
- 提高浅色与深色主题的辅助文字对比度，修正深色主题下继承到浅色正文颜色的问题。
- 配合字体调整按钮换行、表单间距、侧栏和步骤列表布局；概览装饰区域取消缩放文字，最小窗口保持可读字号。

验证范围包括真实 Windows Tauri / WebView2 下的概览、场景列表、运行历史、应用库、工作区、导入导出、设置、凭据与应用表单、场景设置、Cron 和高级画布，覆盖浅色 / 深色主题、1240×820 与 920×640 窗口。开发工具确认场景设置使用本机 Microsoft YaHei UI 字体；页面样本中表单与说明字号均不低于 13px。

17 项前端测试、9 组 Cron / 应用捕获桌面检查及 7 组场景排序 / 快捷启动回归检查通过；46 个界面样本未发现页面横向溢出或脚本错误。

本地制品位于 `artifacts/typography/windows/`，包含安装包与便携 ZIP。构建未签名，更新器未配置；macOS 未做本轮实机验收。
