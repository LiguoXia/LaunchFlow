# LaunchFlow v0.4.12

Windows x64 预发布验收版，修复默认场景启动诊断和微信中文文本录制。

- 启动检查失败会显示原因、留下运行历史，并提供“允许默认场景自动执行”入口。已运行实例收到首次启动指令会执行默认场景，同一实例重复指令不会重复执行。
- 普通登录启动路径正确引用并检查登记是否过期。
- 设置新增 Microsoft Autologon 官方配置入口。Windows 先自动登录，再由 LaunchFlow 执行默认场景；密码不写入工作流，普通锁屏不会自动解锁。
- 录制增加 TextPattern 与输入框检查；移除文本相关动态名称，回放确认文字确实更新。录制审阅可直接编辑文本。

**升级后请在设置中点击“允许默认场景自动执行”，确认启动检查通过。此前漏录的中文输入需要重新录制；0.4.10 及以前的整窗点击也需要重新录制或拾取。**

安装包和便携包均未签名，需手动升级；便携版保留完整 native 目录。源码与本机制品版本一致，验证项目见 verification.json。测试只使用独立窗口和数据，未操作微信聊天或更改 Windows 登录凭据；实际重启、自动登录与真实微信输入法仍需用户验收。

详情：[启动与中文录制修复](../STARTUP-TEXT-FIX.md)。
