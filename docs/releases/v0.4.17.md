# LaunchFlow v0.4.17

Windows x64 本地验收版，增加场景拖拽排序与概览快捷启动。

- “我的场景”右上角增加拖拽手柄，可拖动调整顺序，也支持 Alt + 方向键。搜索结果内排序保留其他场景；编辑和重命名不改变排序。
- 场景操作栏在重命名与默认场景图标之间增加闪电图标，可添加或取消快捷启动，选中后实心高亮。
- “概览”的默认启动场景下方新增“快捷启动”栏目，显示场景名、任务数和启动按钮。添加、取消、改名和删除立即同步，排列跟随“我的场景”。
- 顺序及快捷启动状态重启后保留；旧数据自动迁移。新建、复制及导入的场景追加到末尾，快捷启动沿用已有参数配置和敏感动作确认流程。

操作说明见 [场景排序与快捷启动](../SCENE-ORDER-AND-QUICK-LAUNCH.md)。

验证：前端 15 项、核心 92 项测试通过（另有 1 项需交互桌面的原生 GUI 测试未运行），Clippy 全工作区检查通过。真实 Windows WebView2 的 7 组场景排序与快捷启动检查、7 组默认场景回归检查通过，覆盖鼠标拖拽、搜索与跨行排序、重启、快捷启动执行、参数弹框、延迟响应和失败恢复。浅色 / 深色、正常 / 窄窗口无卡片横向溢出或页面脚本错误，同时修正概览标题在深色主题中的文字对比度。

提供 Windows x64 安装包和便携 ZIP，均为未签名构建；更新器未配置。macOS 尚未完成实机验收，本版本不标记为 V1 Release Candidate。
