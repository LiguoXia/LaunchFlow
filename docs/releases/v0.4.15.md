# LaunchFlow v0.4.15

Windows x64 预发布验收版：场景名称同步与全步骤体验模板。

- 编辑器修改场景名称后，切换到“我的场景”立即同步正式名称；保留未保存的步骤草稿、默认状态及历史快照。
- “我的场景”新增 Windows 体验模板入口，可载入、编辑、运行与删除后重新载入。
- 主场景 42 步，覆盖全部 32 种步骤类型；使用记事本、资源管理器、默认浏览器和随包提供的练习窗口，包含专用演示 Secret、分支、子流程与工作区恢复。
- 保留 0.4.14 的 QQ Secret 输入修复和简单编排拖拽排序。

操作说明：[场景名称同步与 Windows 体验模板](https://github.com/LiguoXia/LaunchFlow/blob/v0.4.15/docs/SCENE-SYNC-AND-TEMPLATE.md)。在“我的场景”点击“载入体验模板”，可预览、载入与运行；模板不会替换现有默认场景，也不会在载入时自动运行。

已验证：前端 12 项测试、Rust Core 89 项测试（另有 1 项交互测试忽略）、Clippy，以及场景编辑和模板两组 Windows 桌面验收（各 7 项）。未修改的完整体验模板连续运行两次成功。公开验收摘要见 `verification.json`，制品 SHA-256 见 `SHA256SUMS.txt`。

提供 Windows x64 安装包和便携 ZIP，均为未签名构建。更新器未配置，请手动下载安装包升级。macOS 尚未完成实机验收；本版本不标记为 V1 Release Candidate。
