# LaunchFlow v0.4.18

Windows x64 本地验收版，增加 Cron 触发、运行来源和应用库批量捕获。

- 场景设置新增“Cron 定时”，支持 5 段或含秒的 6 段表达式、错误提示、常用示例和接下来 3 次执行时间预览。按本机时区运行，保持 LaunchFlow 在前台或托盘即可；关闭或休眠期间不补发。
- 运行历史新增“触发方式”列，区分手动、快捷启动、系统登录、Cron、其他定时、快捷键、设备事件和恢复 / 重试等来源；Cron 记录本次触发的原始表达式，后续编辑不改写历史。
- 应用库新增“捕获工作区应用”和“捕获系统默认应用”。后者包含 Windows 内置常用应用和当前默认浏览器、邮件、图片、音乐、视频、PDF 与文本应用。
- 捕获后可搜索、勾选和批量添加；已有应用勾选置灰，同一程序的多个窗口或默认关联合并显示。支持商店应用图标与启动，保留应用库中已有的自定义配置。
- 捕获失败支持重试，添加失败保留选择；优化浅色、深色和窄窗口中的捕获弹框与历史列表。

操作说明见 [Cron、触发来源与应用捕获](../CRON-AND-APPLICATION-CAPTURE.md)。

验证：前端 17 项、核心 97 项测试通过（另有 1 项需交互桌面的原生 GUI 测试未运行），Rust 格式与 Clippy 全工作区检查通过。真实 Windows Tauri / WebView2 的 9 组新增功能检查和 7 组场景排序 / 快捷启动回归检查通过；包含实际 Cron 自动执行、捕获后启动计算器、重启持久化、错误注入与恢复，页面无脚本错误。

提供 Windows x64 安装包和便携 ZIP，均为未签名构建；更新器未配置。macOS 尚未完成实机验收，本版本不标记为 V1 Release Candidate。
