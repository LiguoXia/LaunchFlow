# LaunchFlow v0.4.27

修复工作流编辑器 Pick Element 第二次拾取失效，以及弹窗无法用鼠标关闭的问题。

- 每次拾取都可重新选择应用、窗口和控件，不再受上一次保存的窗口标题限制。组合快捷键、输入文本、点击、激活窗口等全部 GUI 步骤以及 Fallback 共用修复。
- 拾取器正确放行 LaunchFlow 自身的关闭 / 停止按钮点击；目标应用中的选取点击不会穿透为实际操作。移出目标后清除旧高亮，避免选中上一次悬停的控件。
- 关闭弹窗或按 Esc 都会结束拾取，并保留原定位配置。修复关闭弹窗时表单误触发删除定位器的问题。
- 上一次原生拾取会话释放后才开放下一次拾取，避免快速重开与旧鼠标钩子冲突；启动中防止重复点击。
- 新增[中文详细使用手册](../LaunchFlow-详细使用手册.md)，包含 33 种步骤、12 种触发器、Highlight、七种定位器与 Fallback、工作区、凭据和故障排查。

Windows 实际桌面回归：`npm run test:picker` 使用隔离数据与自有测试窗口，覆盖全部 20 种 GUI 步骤各两次拾取（第二次切换窗口）、Fallback 重复拾取、真实鼠标关闭、取消保留配置与 Esc 后重开，共 23 项。`npm run test:recorder` 验证点击拦截、录制暂停、文本合并及密码遮蔽。前端测试、自动化配置测试、格式和静态检查通过。

macOS 同步修复拾取范围、控制窗口点击及旧悬停状态，Intel / Apple Silicon 包由各自平台构建并检查启动。Mac 上的真实鼠标拾取仍需目标设备验收。

提供 Windows x64 安装包 / 便携 ZIP，以及 macOS Intel、Apple Silicon 的 DMG / ZIP。macOS 最低版本为 13。当前仍为预发布：Windows 无发行证书签名；macOS 使用 ad-hoc 签名，未公证；自动更新未配置，请手动升级。

升级前保存当前编辑，从托盘退出旧版，再运行完整解压的新版。现有场景不需要重新创建。
