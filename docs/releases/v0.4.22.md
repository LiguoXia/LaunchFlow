# LaunchFlow v0.4.22

「激活窗口」新增 Windows 隐藏主窗口恢复，用于 Codex 等缩到系统托盘、仍保留主窗口的应用。

- 过去只查找可见窗口，托盘应用的隐藏主窗口被过滤。现在激活步骤会同时查找可恢复的隐藏主窗口，先显示窗口，再确认前台焦点；隐藏前的最大化状态保留。
- 工作流编辑器 → 激活窗口 → 「桌面与托盘窗口」可选择标注「隐藏 / 托盘」的目标。已录制的激活步骤自动使用新逻辑，无需重新录制。保存的定位只包含应用名、窗口标题和类名，不保存临时 PID 或句柄。
- 普通点击、文本输入、等待窗口和录制选择仍要求窗口可见。隐藏辅助窗口、工具窗口、被其他窗口拥有的窗口不作为恢复目标；多个窗口同时匹配时要求补充定位条件，不任意选择。
- 诊断信息新增 `hiddenRestoreRequested` 和 `targetVisible`，可区分“未找到主窗口”“显示窗口超时”和“前台激活被拒绝”。

使用方式：应用保持运行，在激活步骤选择其主窗口并保存，之后缩回托盘仍可通过该步骤恢复。如果某应用关闭主窗口后会销毁它、仅留下后台进程，应先添加「启动应用」步骤重新打开主窗口；本功能不会通过后台进程名猜测并重新启动程序。

验证采用独立 NotifyIcon 托盘测试应用及隔离的真实 Windows Tauri / WebView2：7 组检查覆盖隐藏目标列表、保存定位、工作流恢复、最大化保留、普通最小化、多匹配 / 失效句柄保护、LaunchFlow 重启后回放；另有 14 项原生窗口焦点测试、18 项前端测试及 Rust 回归。没有关闭或操作用户正在使用的 Codex 窗口；macOS 未作本轮实机验收。

Windows x64 本地安装包与便携包位于 `artifacts/tray-activation/windows/`。构建未签名，未配置自动更新；本轮未发布 GitHub。
