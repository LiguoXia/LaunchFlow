# LaunchFlow v0.4.10

Windows x64 预发布验收版。首次发布完整源码，包含 Tauri / Rust 工作流引擎、React 编辑器和 Windows / macOS 原生自动化实现。

## 本版修复

- 录制回放请求激活窗口后，等待真实前台状态，避免过早报 `focusDenied`。
- 为本次原生助手交接前台权限，异步恢复最小化窗口并保留最大化布局。
- 键盘、鼠标输入前再次核验目标焦点，失焦时停止输入。
- 运行详情的复制诊断日志、诊断 ZIP 增加 GUI 错误码、焦点阶段和等待耗时，不包含窗口标题、聊天或输入内容。
- 修复重复的 `GUI automation failed` 报错前缀。已有录制无需重新录制。

此源码快照同时包含应用预授权启动、工作区捕获与关闭、应用图标、默认场景、录制审阅修复和解锁前桌面准备等此前功能。

## 下载与校验

- `LaunchFlow_0.4.10_x64-setup.exe`：Windows x64 安装包。
- `LaunchFlow_0.4.10_windows-x64-portable.zip`：解压整个目录，保留 `native` 子目录，运行 `LaunchFlow.exe`。便携包使用当前用户的应用数据目录。
- `SHA256SUMS.txt`：制品和验证记录的 SHA-256。
- `manifest.json`：文件大小、哈希、签名状态。
- `verification.json`：本版测试结果与未验证项。
- GitHub 自动提供此标签对应的源码 ZIP / tar.gz。

需要 Windows 10/11 x64、WebView2 与系统 .NET Framework。安装前退出正在运行的 LaunchFlow。当前制品未签名；没有配置自动更新，使用安装包手动升级。

## 验证情况

83 项 Rust 核心测试、11 项前端测试、9 项原生焦点测试、6 项管理员关闭路由测试通过，Clippy 通过。真实 WebView2 / Tauri / 原生助手的 4 项录制审阅流程和 1 项锁屏输入拦截、诊断传递流程通过。安装包版本、内置原生助手及便携包文件校验通过。

发布时本机处于 LockApp 锁屏，解锁后的真实前台切换、最小化/最大化回放与微信实际流程尚未完成复验。一个旧的交互式核心测试默认跳过。macOS 实机编译/运行、代码签名、公证、真实更新和干净系统安装验收尚未完成。本版不标记为 V1 Release Candidate，不提供未经验证的 macOS 二进制制品。

若回放仍失败，请从「运行历史 → 对应失败运行」复制诊断日志；详细实现与复验方式见 [GUI 焦点修复说明](../GUI-FOCUS-FIX.md)。
