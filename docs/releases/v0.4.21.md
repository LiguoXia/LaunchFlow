# LaunchFlow v0.4.21

场景设置 → 触发器新增「指定时间」，用于在指定日期和时间自动运行一次场景。

- 输入格式严格为 `yyyy-MM-dd HH:mm:ss`，例如 `2026-12-31 09:30:00`，按本机时区解释。输入时显示校验结果，保存时再次校验；拒绝不完整格式、无效日期、非闰年 2 月 29 日、越界时分秒，以及夏令时导致的不存在或歧义时刻。
- 秒级调度。到达时间后触发一次；如果 LaunchFlow 关闭或电脑休眠导致错过，恢复后补执行一次。输入过去时间时会提示这一行为。禁用的触发器不执行；重新启用已到期且尚未执行的预约会补执行。
- 一次性执行标记保存在本机数据库，重启、重复轮询、修改其他场景内容不会重复触发。改变预约时间可建立新预约；同一触发器改回已经执行的时间不会重新触发。运行失败或被场景策略拒绝后不会自动反复补发，可在检查原因后手动重试。
- 运行历史的触发方式显示「指定时间」及该次运行保存的预约时间。
- 保留 v0.4.20 中录制文本跨应用重启后的定位修复。

验证：18 项前端测试、核心 Rust 测试套件（包含秒边界、重复轮询、数据库重新打开、时间回拨、改期、禁用与错过时间补执行）、5 组真实 Windows Tauri / WebView2 桌面检查通过。桌面检查使用隔离数据库和短暂等待步骤，实际关闭并重新启动 LaunchFlow 验证防重复执行。一个原有的交互桌面 Rust 测试按默认设置跳过。
