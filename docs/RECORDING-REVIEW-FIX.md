# 录制审阅重复弹框修复 · 0.4.9

旧版只用编辑器组件内的引用记录“已展示”，切换页面后引用重置，后台仍保存上一轮停止的录制，所以重新进入编辑器会再次弹出“审阅录制 Actions”。

现在关闭审阅框、放弃录制或确认插入时，通过录制会话 ID 在后台标记已处理并清理暂存动作。切换页面和 WebView 重载后仍保持已处理；旧审阅不能消费新录制，进行中的会话也不能被审阅操作清空。插入动作只执行一次，连续点击会合并处理。初始化查询不会覆盖之后收到的新会话事件。

原生录制器会自动加入 activateWindow。如果录制只有这个准备动作而没有实际用户动作，不弹审阅框。新的有效录制仍正常审阅。

验证：`npm run test:recording-review` 使用独立测试窗口、实际录制与真实 Tauri IPC，覆盖关闭、放弃、插入后再次打开编辑器、WebView 重载以及空录制。核心会话测试覆盖确认幂等、旧 ID 和活动录制保护。证据在 `test-results/recording-review`。
