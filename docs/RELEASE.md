# Signed distribution

The checked-in application is a local Phase 4 build. An unsigned installer is for acceptance only and must not be labelled V1 Release Candidate. The manual `Signed release candidate artifacts` workflow builds Windows x64 and macOS Intel / Apple Silicon artifacts, uploads them to the workflow run, and does not publish a GitHub release or change an update server.

## Release environment

Create a protected GitHub environment named `release`. Configure these public variables:

- `LAUNCHFLOW_UPDATE_URL`: HTTPS updater manifest endpoint (Tauri target / architecture / current-version placeholders are supported).
- `LAUNCHFLOW_UPDATE_PUBLIC_KEY`: the base64 public key generated by Tauri's signer.
- `WINDOWS_TIMESTAMP_URL`: the timestamp service supplied by the certificate issuer.
- `APPLE_SIGNING_IDENTITY`: Developer ID Application identity, including the team ID.

Configure secrets:

- `TAURI_SIGNING_PRIVATE_KEY`, and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` if the key is encrypted.
- `WINDOWS_CERTIFICATE_BASE64`, `WINDOWS_CERTIFICATE_PASSWORD` for an exportable certificate supported by SignTool. Hardware / cloud EV certificates require replacing the signing step with the issuer's supported signer.
- `APPLE_CERTIFICATE_BASE64`, `APPLE_CERTIFICATE_PASSWORD` (Developer ID Application PKCS#12).
- `APPLE_API_ISSUER`, `APPLE_API_KEY`, `APPLE_API_KEY_BASE64` (App Store Connect notary API `.p8` content).

Never store these private credentials in this repository or a scene. CI imports signing material into an ephemeral runner, signs both native workers, then builds the main app and installer. macOS builds enable hardened runtime and use Tauri notarization. `LAUNCHFLOW_NATIVE_PREBUILT=1` is reserved for the step after native signatures are verified so the Swift workers are not recompiled after signing.

`node scripts/release-preflight.mjs` fails closed if release configuration is missing and writes public settings to ignored `.local/release.json`. The endpoint and public key are also compiled into the host. There is no UI or imported-scene override for them. Development builds disable update calls regardless of configuration.

## Required release gates

1. Run unit tests, Clippy and frontend checks on all build targets; run GUI / workspace / vault acceptance on each actual supported OS and architecture. A cross-compilation result is not a macOS runtime test.
2. Run the signed workflow. Verify Windows Authenticode, macOS code signature and notarization ticket, and the artifact SHA-256 inventory. No unsigned fallback is permitted in this workflow.
3. Confirm updater signatures include `version:<release version>` in the trusted comment. `requireSignedVersion` is enabled so a genuine old artifact cannot be paired with a forged newer version in update metadata. Tauri's updater validates both the artifact signature and its signed version before installation.
4. Serve candidate artifacts on a staging HTTPS endpoint. Exercise valid update, tampered download, wrong key, wrong signed version, unavailable endpoint, cancellation / network failure, and active-workflow installation rejection. Verify manual confirmation and successful relaunch on Windows and both Mac architectures. Do not infer this result from file presence or an unsigned build.
5. Validate the installer in a clean Windows user account / Mac machine: fresh install, upgrade, uninstall, preserved user data, login entry, tray lifecycle, permissions after signing, and Keychain identity continuity.
6. Close all release blockers in `V1-RELEASE-READINESS.md` before changing the release label to V1 Release Candidate. Publish the platform manifest only after these checks; this repository contains no auto-publish job.

The updater checks only on request, enforces HTTPS including redirects, limits the download to 256 MiB and five minutes, blocks installation while workflows / recording are active, and never bypasses UAC or Keychain authorization. Failed checks or downloads leave the current app usable. Native effects use Tauri's public window-effects configuration; no macOS private API is enabled.
