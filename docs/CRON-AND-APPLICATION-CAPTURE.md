# Cron、触发来源与应用捕获

适用版本：LaunchFlow 0.4.18。Windows 已完成本机验收。

## 设置 Cron 触发

1. 打开场景的工作流编辑器，进入“场景设置”。
2. 添加触发器，将“触发方式”选择为“Cron 定时”。
3. 填写表达式，查看校验结果与接下来 3 次执行时间，勾选“启用”并保存场景。
4. 保持 LaunchFlow 在前台或托盘运行。到达时间后，场景使用已保存的步骤与该触发器的参数执行。

支持以下格式，不包含年份字段：

| 格式 | 字段                | 示例              | 含义         |
| ---- | ------------------- | ----------------- | ------------ |
| 5 段 | 分 时 日 月 星期    | `*/5 * * * *`     | 每 5 分钟    |
| 5 段 | 分 时 日 月 星期    | `0 9 * * MON-FRI` | 工作日 09:00 |
| 5 段 | 分 时 日 月 星期    | `0 18 * * 0`      | 每周日 18:00 |
| 6 段 | 秒 分 时 日 月 星期 | `*/30 * * * * *`  | 每 30 秒     |

支持通配符 `*`、范围 `-`、列表 `,` 和步长 `/`。星期 0 和 7 都表示周日，也可用 MON–SUN。日期与星期都有限制时采用 POSIX 的“或”语义：任一匹配即触发。例如 `0 9 1 * MON` 表示每月 1 日和每周一 09:00。

执行时间跟随本机时区。Cron 独立每秒检查，避免网络或桌面传感器阻塞定时检查；它不是实时系统。应用关闭、休眠期间错过的时间不补发，也不会唤醒电脑。同一配置和本地时间槽只执行一次，重启或时钟回拨不会重放已领取的时间槽。修改表达式会形成新的调度配置。

场景原有的并发策略（忽略、排队、重启）、参数校验和敏感动作策略继续生效。“每次询问”的敏感动作不会因 Cron 触发而自动获准；需要无人值守执行时，请在场景设置中检查并配置合适的策略。

## 查看运行来源

运行历史增加“触发方式”列，运行详情也显示来源。可区分手动运行、概览快捷启动、托盘启动、系统登录 / 默认场景、LaunchFlow 启动、Cron、每日 / 每周定时、全局快捷键、网络和设备变化、恢复 / 重试、子流程与单步测试。

Cron 显示触发本次运行的表达式；快捷键与其他定时触发显示对应配置。来源与触发器 ID 在创建运行时记录，细节读取运行的场景快照，之后修改场景不会改写历史。旧记录没有触发器 ID 时，只在同类触发器唯一的情况下显示配置，避免把多个触发器的配置混淆。

## 捕获工作区应用

在“应用库”点击“捕获工作区应用”。捕获当前桌面窗口所属的应用，同一应用的多个窗口合并；搜索后勾选需要的应用，点击“添加所选”。这不会复制窗口中的项目、标签页或文档，也不会自动添加后台服务。

未添加项默认不勾选；已经在应用库中的项目自动勾选并置灰。添加成功后列表立即更新，重新捕获和重启后仍会识别已有应用。可使用“全选当前可添加项”选择当前搜索结果；捕获失败可重试，添加失败保留勾选。

## 捕获 Windows 默认应用

在“应用库”点击“捕获系统默认应用”，包括两类：

- 已安装的 Windows 内置常用应用，如记事本、计算器、画图、截图工具、照片、终端、文件资源管理器、任务管理器等。实际列表取决于本机安装情况。
- 当前账户的默认浏览器（HTTP / HTTPS）、邮件，以及 JPG、PNG、MP3、MP4、PDF、TXT 文件关联应用。

同一程序承担多个默认角色时合并显示类别。Windows 商店应用使用已注册的应用标识启动，并显示应用图标。未设置默认应用、解析结果只是系统选择器，或无法读取路径时，会提示原因，不会将选择器当作实际应用添加。

捕获只读取系统信息，不会启动程序或修改默认关联。批量添加使用事务，重复应用不重复写入，也不会覆盖原应用的启动参数、管理员设置或 Ready 条件。可通过应用库继续编辑捕获后的配置。

Windows 默认应用捕获目前仅在 Windows 显示。macOS 工作区捕获沿用已有实现，本版未做 Mac 实机验收。

## 开发验证

`npm run test:cron-capture` 启动独立数据目录中的真实 Windows Tauri / WebView2 应用，验证勾选添加、已有应用禁用、内置应用别名去重、商店图标与计算器启动、Cron 预览及实际定时执行、历史来源、重启保持、错误重试和浅色 / 深色窄窗口。若用户已打开计算器，脚本跳过启动验证，避免关闭用户进程；报告会明确记录跳过。

Cron 语法采用 [croner 3.0.1](https://docs.rs/croner/3.0.1/croner/)。默认关联读取使用 [Windows ASSOCSTR](https://learn.microsoft.com/en-us/windows/win32/api/shlwapi/ne-shlwapi-assocstr)，商店应用识别基于 [Windows AUMID](https://learn.microsoft.com/en-us/windows/configuration/store/find-aumid)。
